🔄 The 9 Universal Transactional Lifecycle Stages
Closed-Loop Feedback • Zero Open Branches

Every mutation—whether a mentor pairing invite, a sadhana log submission, or an admin screen authorization toggle—flows through these strict sequential phases ensuring data integrity before and after network connectivity is restored.

STAGE 0 LOCAL
Mutation Inception & Nonce
The user triggers an action (e.g. toggles Screen Auth Matrix checkbox or assigns downline role). System generates a hardware nonce, client timestamp, and UUIDv5 transaction hash.
crypto.randomUUID() hardwareNonce L0 Client
STAGE 1 CLIENT
Schema Sanitization & Guard
Input passes through sanitizer.js and FormValidator.js. Invalid types, script injections, or privilege escalations are trapped and rejected immediately.
Sanitizer.cleanText() XSS Guard Schema L1
STAGE 2 OPTIMISTIC
Optimistic Local Staging
DOM UI updates immediately without waiting for server response. Mutation commits to localStorage (e.g. sk_auth_matrix_v5 or sk_profile_role_matrix_v1).
localStorage.setItem() 0ms UI Latency Fast UX
STAGE 3 BROADCAST
Cross-Tab Peer Propagation
A dual message is dispatched via BroadcastChannel across 'sk_matrix_channel' and 'spiritual_karim_sync' so open sibling tabs re-render dynamically.
BroadcastChannel.postMessage Cross-Tab L2 < 15ms
STAGE 4 QUEUE
Offline Staging Queue
If network is offline or unacknowledged, transaction enqueues into sk_sync_queue with retry counters, exponential backoff (1s, 2s, 4s, 8s), and circuit breaker protection.
sk_sync_queue Exponential Backoff Resilient
STAGE 5 CLOUD DUAL-WRITE
Firebase RTDB & REST Ingestion
FirebaseSyncEngine synchronously pushes to Firebase RTDB node (e.g. /auth_matrix, /profile_role_matrix) and dual-writes to Backend REST endpoints.
FirebaseSyncEngine POST /api/auth-matrix Dual-Write
STAGE 6 CONSENSUS
Monotonic Conflict Resolution
If multiple devices modified the same profile or permission simultaneously, the system uses Last-Write-Wins (LWW) with Lamport vector timestamp tie-breakers and hardware nonce deduplication.
Lamport Monotonic Clock LWW Consensus Deduplicated
STAGE 7 SCOPING
MLM Downline Lineage Scoping
Data reaches clients filtered by International MLM rules: Masters see the entire tree; Healers see downline members; Trainees & Devotees see self-only unless granted extra roles.
getScopedDownlineProfiles Recursive Lineage Least Privilege
STAGE 8 AUDIT
Immutable Audit Trail & Ack
Transaction receipt commits to /telemetry/audits. Queue record is pruned from sk_sync_queue, and client displays positive confirmation toast to user.
Audit Immutability Queue Ack / Prune Closed Loop
