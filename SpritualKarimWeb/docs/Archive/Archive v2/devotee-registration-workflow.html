Accidental Tab Close / Refresh		 Devotee closes browser while on Waiting Screen waiting for mentor approval. Page load checks sk_devotee_induction_session and spiritual_karim_pairing_invites. Page recognizes existing session, bypasses blank wizard, and immediately renders Waiting Screen with applicant details. Closed Loop: Heartbeat polling resumes seamlessly without creating duplicate invite records. Session maintained in localStorage; zero data loss.

Closed Loop (Branch C): Devotee re-uploads only the requested ID document; invite immediately returns to Mentor queue. Logged to sk_appeals and Firebase as INFO_REVISION_SUBMITTED.

Accidental Rejection		 Mentor accidentally clicks Reject on mobile touch screen. Rejection requires confirmation modal with mandatory reason selection. Status logged in sk_appeals; original invite preserved.

24h SLA Expiry Window		 Mentor is traveling and does not review invite within 24 hours. expiresAtMs < Date.now() triggers expired state transition. Automated warning ping sent to mentor at 18 hours. At 24h, invite marked EXPIRED. Closed Loop (Branch D): Devotee clicks "Refresh Token"; token re-queues with +24h window after cooldown backoff. resendCount incremented in spiritual_karim_pairing_invites.

Elevator / Subway Disconnect		 Devotee clicks Submit button while entering elevator (network drops). navigator.onLine === false or fetch error caught in Promise. Persistent offline queue in localStorage; zero submission drops.
11 Lineage
Circular Sponsoring Cycle		 Candidate tries to register with mentor who is actually in candidate's downline. ProfileModel.isCircularSponsor() traverses downline tree using recursive visited set. Modal warns: "Lineage Conflict: Selected mentor is already in your downline network". Closed Loop: Form blocks circular upline link and displays Sansthan Founder Master Root option. Prevents database graph corruption and infinite recursion.
