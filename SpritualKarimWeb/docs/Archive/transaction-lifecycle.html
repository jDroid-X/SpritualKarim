🔂 10-Stage Universal Spiritual Lifecycle — All Objects Follow This Path

Profile • Sadhana • House Clean • Pairing Invite • Remedy • Lineage • Healer Certification • Firebase Sync Node

1
📝
CREATE
Initiate
Capture new devotee / spiritual object with all required details via one of 4 registration systems.
  • Admin creates via Masters Portal (1-step)
  • Seeker self-registers via join.html (5-step)
  • Healer sends Share & Pair Invite (2-step)
  • Role Tier assigned (Admin/Healer/Trainee/Devotee)
  • Auto-generate 16-Digit Reference Code
  • Duplicate email + phone check fires
  • Stored: sk_admin_profiles_v3
2
✅
VALIDATE
Guard
Validate data, rules, policies, and boundary constraints before object proceeds.
  • XSS sanitize all inputs (escapeHtml)
  • Sponsor Ref Code existence check
  • Circular sponsor tree detection
  • 24h Security PIN verification
  • Race condition guard on duplicate
  • Firebase Security Rules enforced
  • Required fields: Name, Phone, Role
3
🏻
ASSIGN
Link
Assign to correct Mentor/Healer upline and set role tier hierarchy based on RBAC rules.
  • Upline Healer linked via Sponsor Code
  • Default Mentor: Karim Ji (Founder)
  • Role Tier: MASTER/HEALER/TRAINEE/DEVOTEE
  • Org Level auto-calculated (1-10)
  • Portal View assigned per role tier
  • RBAC Auth Matrix rules applied to UI
  • 5-Level Genealogy Tree position set
4
📊
REVIEW / APPROVAL
24h Gate
Review by upline Healer or Admin and decide required approvals before proceeding.
  • Pending Approval Bell on Dashboard
  • Upline reviews devotee application (24h)
  • Count Badge shows pending count
  • Approval auto-expires at 24h boundary
  • Healer verifies 4 Sacred Pillars consent
  • QR PIN one-time verification token
  • Status: Pending → Approved/Rejected
5
🔥
EXECUTION
Active
Devotee executes the spiritual task or sadhana practice as per the 4 Sacred Pillars guidance.
  • 3 Diya Sadhana: 6:15-7:00 PM window
  • Daily Japa: 108 repetitions
  • House Clean: Level 1 (Self Home)
  • Ancestral Lineage: 3-Gen data entry
  • Remedy prescribed (Tab 2: Seeker)
  • Goli Gyan Guide referenced
  • Mentor notified via Telegram Bot
6
📊
MONITOR
Track
Track progress, KPIs, SLA milestones, and completion status across all sadhana levels.
  • 11 Malas Streak Target (daily)
  • House Clean: 3-Level Progress
  • Sadhana completion % per level
  • Firebase Heartbeat: 15s interval
  • Session Timeout Monitor: 25m warn
  • Cross-tab sync via Storage Events
  • Dashboard progress tiles per Tab
7
🏆
COMPLETE
Milestone
Mark as complete after successful execution and level verification by Mentor/Healer.
  • House Clean Level 1 → 2 → 3 completed
  • Sadhana: Trainee level unlocked
  • Genealogy tree tier count updated
  • Healer Connect Tab activated
  • Completion records written to Firebase
  • Mentor formally marks level complete
  • Profile status updated: Trainee → Healer
8
🔒
CLOSE
Certified
Close the lifecycle transaction, update final records, and notify all related parties of completion.
  • Healer certification achieved (Siddhi)
  • Role upgraded: TRAINEE → HEALER
  • Certified Healers Hub card activated
  • RBAC Matrix updated for new role
  • 5-Level tree position as Healer node
  • Firebase /profiles record finalized
  • Telegram notification to Founder
